# FleetCast agent instructions

Read README.md, CLAUDE.md and docs/BRIEF.md. The same scope and integrity rules apply.
Default Codex assignment: independent reviewer after Claude has stopped editing.
Follow prompts/CODEX_REVIEW.md; do not assume another agent actually ran any command.

Priority: valid problem definition, as-of features, chronological evaluation,
reproducible numbers, honest claims, then UI clarity. More code is not a success metric.

Do not rewrite the project, add frameworks, publish, contact the employer or spend
money. Do not run two writers against the same working tree. Preserve existing
real-data results and disclose when a test period has already been examined.

A test pass is not proof of real-world causality or of the data's completeness.
Check source hashes and the stored predictions; recompute metrics independently.
Write REVIEW.md with severity, file/line evidence, and exact tests run. Do not
claim to have invoked Claude/ChatGPT or any external agent unless a tool did so.
